# Linux-Log-File-Analysis-Automation-and-SIEM-Visualization
SOC log analysis project progressing from manual review to automation to SIEM visualization. Analyzed Linux auth logs for suspicious activity, built a Python script to auto-detect and export findings to CSV, then ingested logs into Splunk to query and visualize patterns using SPL.
